# Development roadmap

## Stage 0 — repository foundation (this feature branch)

- Three real platform entries, local app discovery/launch surfaces, local-first browser shortcuts, input validation, basic automated checks.
- Document third-party attribution, privacy/security boundaries and MIPS gaps.
- Reviewable PR; main-branch ruleset remediation remains an administrator/owner gate if GitHub App API refuses settings access.

## Stage 1 — verified functional preview

- Run Android SDK build and emulator Home-role, reboot, package updates, foldable/rotation and recovery scenarios.
- Run Linux on actual session with GIO, XDG search order, desktop-entry visibility, DBus activation and keyboard.
- Run browser CI and manual keyboard/screen reader regression across supported browsers.
- Add Android layout edit/reorder, icon management, widgets via AppWidgetHost, resilient saved state and local import/export.

## Stage 2 — advanced customization

- Workspaces and folders, drag/drop, gestures, adaptive tablets, profile portability, icon packs, configurable dock, widget scaling and backup/restore.
- Opt-in GoreeCloud Mesh sync only after Identity authentication, GoreeShield privacy requirements and Wardveil security contracts exist.
- Accessibility acceptance on real devices and battery/performance evidence.

## Stage 3 — release qualification

- Security review, upstream license notices, permission and accessibility audits, signed releases, rollback, installer/uninstaller testing, versioning and independent hardware acceptance.
- Do **not** claim Nova/Samsung feature parity, production safety or Anchor/Stable status before evidence exists.
