- **Pinned Git blob:** `68ea82c4657253a1396376f715d3582f1417b9ac`.
- **Consumer repository:** `GoreeCloud/launcher`, Development branch `feat/lawnchair16-glaze-foundation`.

- **Android derivatives:** `res/drawable/goreecloud_launcher_foreground.xml`, `goreecloud_launcher_monochrome.xml` and `goreecloud_launcher_background.xml`.
- **Icon design:** blue gradient rounded workspace tile with four rounded light cells and a blue central point, rather than a G glyph.
- **Optical fit:** preserve the canonical 64×64 shapes centered within the 108dp adaptive viewport; the neutral outer field uses the approved #F7FAFF.
- **Source contracts:** `scripts/verify_onboarding_brand.py` checks adaptive icon resources.
- **Remaining acceptance:** inspect the installed app icon in Home, app drawer, Android Settings/app info, light/dark wallpaper, and Android themed icon mode. Check compile/packaging before QA distribution.

The platform-wide GoreeCloud parent logo (`official/goreecloud-logo.svg`) is not the Launcher product icon. Earlier temporary open-G artwork is superseded and must not be used as an active application icon.
