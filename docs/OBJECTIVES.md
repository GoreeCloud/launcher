# GoreeCloud Launcher objectives

1. Android: installable, user-selectable Home candidate with visible app discovery, reliable app launching and a non-destructive way back to system settings.
2. Linux: native Qt Quick 6.12.0 app browser; launch applications using desktop-entry standards without shell interpolation.
3. Web: accessible local-first app/bookmark board without requiring a server, accounts or external telemetry.
4. Cross-platform: transparent data flows, explicit permission boundaries, UI consistency using canonical GoreeCloud UI tokens, measured accessibility and performance.
5. Endurance: reproducible builds, reviewable CI, safe migrations and backup/restore plans before stable release.

**Success gates**: successful platform-specific builds, functional/manual keyboard and screen-reader checks, Android physical-device Home recovery, Linux desktop launch verification, browser acceptance, license and source verification, MIPS applicability review and protected main. None is presumed complete from source creation alone.
